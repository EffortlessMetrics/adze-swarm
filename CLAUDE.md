# Claude Code entrypoint

Read [AGENTS.md](AGENTS.md) in full. It is the canonical instruction file for
this repository, including issue-led parallel work, proof, review, continuation,
CI economics and release boundaries. This file does not define a second workflow.

Use focused red/green/refactor cycles and the selected accepted spec. Current
issues/PRs—not a singleton active-goal file or session percentage—identify the
next eligible work. Follow [SPEC_SYSTEM.md](docs/reference/SPEC_SYSTEM.md) and
[the operating model](docs/reference/adze-swarm-operating-model.md).

Technical command references remain in AGENTS, CONTRIBUTING, the justfile and
the actual package manifests. Read support-tier evidence before making a claim.
