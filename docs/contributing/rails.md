# Contributing with Rails

When contributing source-of-truth artifacts:

1. Place durable artifacts under `.rails/`.
2. Register owned artifacts in `.rails/index.toml`.
3. Keep lane sequencing in focused lane trackers under `.rails/lanes/`.
4. Do not use external tool namespaces (`.codex/`, `.spec/`, `.claude/`, `.jules/`) for Rails-owned artifacts.

Use templates in `.rails/templates/` for consistent proposal, spec, ADR, lane, support, policy-reference, and closeout shapes.
