# Support

## Public Adze Users

Use public `EffortlessMetrics/adze` for released-user support:

- **Bug reports**: [Open a public Adze issue](https://github.com/EffortlessMetrics/adze/issues/new?template=bug_report.yml)
- **Questions and discussion**: [GitHub Discussions](https://github.com/EffortlessMetrics/adze/discussions)
- **Feature requests**: [Open a public Adze feature request](https://github.com/EffortlessMetrics/adze/issues/new?template=feature_request.yml)

## adze-swarm Work

Use `EffortlessMetrics/adze-swarm` for development, research, proof, CI
experiments, issue management, and release-candidate preparation.

Before opening swarm work, check the current research board and operating model:

- [research board #617](https://github.com/EffortlessMetrics/adze-swarm/issues/617)
- [release authorization #325](https://github.com/EffortlessMetrics/adze-swarm/issues/325)
- [adze-swarm operating model](docs/reference/adze-swarm-operating-model.md)

Swarm issues and PRs should link to a source-of-truth work item, state the
claim boundary, and include proof commands or the next evidence needed.

## Before Opening An Issue

1. Search the matching repository's existing issues to avoid duplicates.
2. Check the support tiers and proof commands in [`docs/status/SUPPORT_TIERS.md`](docs/status/SUPPORT_TIERS.md).
3. Try to create a minimal reproduction or a concrete research question.

## Release And Install Claims

`adze-swarm` does not authorize release, publish, signing, Cargo-token use, or
crates.io install claims. Those decisions are explicit human release decisions
tracked through #325 or its successor.

## Security Issues

Please **do not** open public issues for security vulnerabilities. See [SECURITY.md](SECURITY.md) for reporting instructions.
